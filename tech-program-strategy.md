## 3. Four-Week Preparation Plan

The next deadlines are months away, so this is a preparation sprint. Repeat the open-source work in the months before each window.

| Week | LFX Mentorship | GitHub Campus Experts |
|---|---|---|
| **1** | Pick 2-3 LF/CNCF projects that match your skills. Read their contributing guides. Set up the dev environment and run the tests. | Claim the Student Developer Pack and confirm your account age and graduation date. List 3 campus-community problems you could solve. |
| **2** | Join the project's Slack/Discord. Fix 1-2 "good first issue" tickets and open the PRs. Skill focus: Go or Python plus Docker/K8s basics. | Plan and announce one small event, such as a Git/GitHub workshop or study jam. Draft an outline for your technical blog post. |
| **3** | Respond to review feedback until the PRs merge. Take on a slightly larger issue or a docs improvement. | Run the event and collect attendee feedback. Publish the blog post (what you taught and what you learned). |
| **4** | Write a one-page proposal for a project idea. Update your resume and pin your best repos. Watch for Term 1 postings. | Finalize the application answers and record the video resume. Update LinkedIn with the event and blog. Get one peer to review everything. |
